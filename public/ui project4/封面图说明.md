# 意难平 Studio · 项目封面图

请将封面图放到本目录，并使用以下文件名（与代码里路径一致）：

**文件名：** `ui project-4.png`

**完整路径：** `public/ui project4/ui project-4.png`

## 建议规格

- 比例：与现有 UI 项目一致（可参考 `ui project1` ~ `ui project3` 的截图比例）
- 格式：PNG 或 JPG（若用 JPG，需把 `ProjectsSection.jsx` 里的路径改成 `.jpg`）
- 建议宽度：约 1200px 或以上，文件尽量压缩后上传

## 项目信息（已配置）

- **中文名：** 意难平 Studio
- **英文名：** What If Studio
- **链接：** https://whatifstudio.saurlax.com/

放好图片后刷新本地 `npm run dev` 或重新部署即可在「我的项目 → UI/UX」中看到新卡片。
